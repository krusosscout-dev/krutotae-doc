# คู่มือการเชื่อมต่อฐานข้อมูลออนไลน์ Google Sheets (Cloud Database)
**ระบบคลังเอกสารและสื่อการเรียนรู้ดิจิทัลสถานศึกษา (TT001)**

---

## 🌟 ทำไมต้องเชื่อมต่อ Google Sheets?
- **ข้อมูลตรงกันทุกเครื่อง (Real-Time Sync)**: ไม่ว่าจะเปิดจากคอมพิวเตอร์โรงเรียน, โน้ตบุ๊ก, แท็บเล็ต, หรือมือถือของครูทุกคน จะเห็นเอกสารที่อัปเดตตรงกันทันที
- **ฟรี 100% ไม่มีค่าใช้จ่าย**: ทำงานบน Google Drive ของโรงเรียน/ครูผู้ดูแลระบบ
- **แก้ไขข้อมูลง่าย**: สามารถเปิดดูและแก้ไขรายการเอกสารผ่านตาราง Google Sheets ได้โดยตรง

---

## 🛠️ ขั้นตอนการติดตั้งง่ายๆ ใน ๓ นาที:

### 📌 ขั้นตอนที่ ๑: สร้าง Google Sheets และเปิด Apps Script
1. เข้าไปที่ [Google Sheets (สเปรดชีต)](https://sheets.new) เพื่อสร้างไฟล์ใหม่
2. ตั้งชื่อไฟล์ เช่น `ฐานข้อมูลคลังเอกสารดิจิทัล TT001`
3. ไปที่เมนูด้านบน เลือก **"ส่วนขยาย" (Extensions)** ➔ **"Apps Script"**

---

### 📌 ขั้นตอนที่ ๒: วางโค้ดระบบเชื่อมต่อ
1. ลบโค้ดเดิมในหน้า Apps Script ออกทั้งหมด
2. คัดลอกโค้ดทั้งหมดจากไฟล์ `google_apps_script/Code.gs` มาวางลงในหน้าต่าง
3. กดปุ่ม **"บันทึก" 💾** (รูปแผ่นดิสก์)

---

### 📌 ขั้นตอนที่ ๓: เผยแพร่เว็บแอป (Deploy Web App)
1. กดปุ่มสีน้ำเงิน **"ทำให้ใช้งานได้" (Deploy)** ที่มุมขวาบน ➔ เลือก **"การทำให้ใช้งานได้รายการใหม่" (New deployment)**
2. คลิกรูปฟันเฟือง ⚙️ เลือกประเภท **"เว็บแอป" (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description)**: `v1.0`
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (อีเมลของคุณ)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน (Anyone)`** *(สำคัญมาก เพื่อให้เว็บสามารถดึงและบันทึกข้อมูลได้)*
4. กดปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
5. หากมีหน้าต่างขออนุญาตสิทธิ์ ให้กด **"ให้สิทธิ์เข้าถึง" (Authorize access)** ➔ เลือกบัญชี Google ➔ กด **Advanced (ขั้นสูง)** ➔ กด **Go to ... (unsafe)** ➔ กด **Allow (อนุญาต)**
6. **คัดลอก "URL ของเว็บแอป" (Web App URL)** ที่ลงท้ายด้วย `/exec`

---

### 📌 ขั้นตอนที่ ๔: นำ URL มาใส่ในระบบ
1. เปิดหน้าเว็บระบบคลังเอกสาร `TT001`
2. ล็อกอินเข้าสู่ **"โหมดแอดมิน" (Admin)**
3. กดปุ่ม **"☁️ เชื่อมต่อ Google Sheets"**
4. วาง URL ที่คัดลอกมาลงในช่อง แล้วกด **"ทดสอบและบันทึกการเชื่อมต่อ"**
5. ระบบจะขึ้นสถานะ **🟢 เชื่อมต่อ Cloud Database สำเร็จ** และดึงข้อมูลเอกสารทั้งหมดไปเก็บไว้บน Google Sheets ของคุณครูทันที!

---

> 💡 **หมายเหตุ**: หากยังไม่ได้เชื่อมต่อ Google Sheets ระบบจะยังคงทำงานด้วยฐานข้อมูลความจำในเครื่อง (Local Database) ได้อย่างสมบูรณ์แบบโดยไม่มีข้อผิดพลาดใดๆ ครับ
