วาง Web App URL ที่ได้จากการ Deploy Google Apps Script (ดูขั้นตอนด้านล่าง)

ขั้นตอนการสร้าง Web App ใน Google Sheets:
  1. สร้างไฟล์ Google Sheets ใหม่ ➔ ไปที่ ส่วนขยาย (Extensions) ➔ Apps Script
  2. คัดลอกโค้ดจากไฟล์ google_apps_script/Code.gs มาวางแล้วกดบันทึก
  3. กด ทำให้ใช้งานได้ (Deploy) ➔ เลือก เว็บแอป (Web app) ➔ ตั้งค่าผู้มีสิทธิ์เป็น ทุกคน (Anyone)
  4. คัดลอก URL ของเว็บแอป มาวางในช่องด้านบนแล้วกด "บันทึกและซิงค์"
