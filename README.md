# ระบบคลังเอกสารและสื่อการเรียนรู้ดิจิทัล (โรงเรียนวัดบางปูน)
**รหัสโครงการ: TT001 • ประจำปีการศึกษา ๒๕๖๙**

แพลตฟอร์มบริหารจัดการสื่อการสอนและคลังเอกสารราชการออนไลน์สำหรับโรงเรียนวัดบางปูน ออกแบบตามแนวคิด *"จัดเก็บง่าย นำไปใช้สะดวก ดีไซน์ทันสมัย และปลอดภัยสูงสุด"* ครอบคลุมโครงสร้าง ๔ ฝ่ายบริหารงานสถานศึกษา พร้อมระบบค้นหาอัจฉริยะ การพรีวิวเอกสารทันที และระบบความปลอดภัยขั้นสูงสำหรับผู้ดูแลระบบ

---

## 🔒 ระบบรักษาความปลอดภัยโหมดผู้ดูแล (Admin Security)
- **บุคคลทั่วไป / ครูผู้ใช้งานทั่วไป**:
  - สิทธิ์ค้นหา ดูตัวอย่าง (Preview) และดาวน์โหลดเอกสาร (Download)
  - ไม่สามารถเข้าถึงหน้าจัดการ อัปโหลด แก้ไข หรือลบเอกสารใดๆ ได้
- **ผู้ดูแลระบบ (Admin Only)**:
  - ต้องกรอกรหัสผ่านเพื่อเข้าสู่ระบบ (Passcode Verification)
  - **รหัสผ่านเริ่มต้น**: `admin1234` หรือ `2569`
  - เมื่อเข้าสู่ระบบสำเร็จ จะปลดล็อกฟังก์ชัน **Drag & Drop Upload**, **แก้ไขรายละเอียดเอกสาร**, **ลบเอกสาร**, และ **ส่งออกข้อมูลสำรอง**

---

## 🌟 โครงสร้างการจัดเก็บข้อมูล ๔ ฝ่ายบริหาร (Information Architecture)
1. **หมวดงานวิชาการ**:
   - หลักสูตรสถานศึกษา / โครงสร้างเวลาเรียน ๒๕๖๙
   - สื่อการสอน / แผนการจัดการเรียนรู้ Active Learning (รูปแบบ ๔ คิด, STEM)
   - แบบฟอร์มนิเทศการสอนออนไลน์และในชั้นเรียน
2. **หมวดงานบุคลากรและบริหารทั่วไป**:
   - คำสั่งโรงเรียน / ประกาศ / ระเบียบการ
   - แบบฟอร์มขออนุญาต (ลากิจ, ลาป่วย, ไปราชการ)
   - แบบฟอร์มเสนอขอรับรางวัล (คุรุชนคนคุณธรรม, นวัตกรรมสร้างสรรค์คนดี)
3. **หมวดงานกิจการนักเรียน**:
   - คู่มือการดำเนินงานสภานักเรียน / คู่มือมาตรการความปลอดภัย
   - เอกสารและแบบรายงานโครงการโรงเรียนคุณธรรม สพฐ.
4. **หมวดงานงบประมาณและพัสดุ**:
   - แบบฟอร์มขออนุมัติจัดซื้อจัดจ้างพัสดุ/สื่อการเรียนรู้
   - รายงานสรุปผลการใช้จ่ายงบประมาณรายไตรมาส

## 🚀 วิธีการนำขึ้น Vercel (Deploy to Vercel.app)

โปรเจกต์นี้เป็น Zero-Config Static Web Application ซึ่งพร้อม Deploy บน Vercel ได้ทันที:

### วิธีที่ 1: ลากโฟลเดอร์วางบนหน้าเว็บ Vercel (เร็วและง่ายที่สุด)
1. เปิดหน้าเว็บ [Vercel.com/new](https://vercel.com/new)
2. คลิกเลือก **folder** หรือลากโฟลเดอร์ `TT001` วางลงบนหน้าเว็บ Vercel
3. ตั้งชื่อโปรเจกต์ เช่น `watbangpun-doc` แล้วกดปุ่ม **"Deploy"**

### วิธีที่ 2: Deploy ผ่าน GitHub
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub Repository ของท่าน
2. ไปที่ [Vercel.com](https://vercel.com) ➡️ กด **Add New Project** ➡️ เลือก Repository แล้วกด **Deploy**
