# ระบบคลังเอกสารและสื่อการเรียนรู้ ครูซอส (โรงเรียนวัดบางปูน)
**รหัสโครงการ: TT001 • ประจำปีการศึกษา ๒๕๖๙**

แพลตฟอร์มบริหารจัดการสื่อการสอนและคลังเอกสารราชการออนไลน์สำหรับโรงเรียนวัดบางปูน ออกแบบตามแนวคิด *"จัดเก็บง่ายและนำไปใช้สะดวก"* ครอบคลุมโครงสร้าง ๔ ฝ่ายบริหารงานสถานศึกษา พร้อมระบบค้นหาอัจฉริยะ การพรีวิวเอกสารทันที และแผงควบคุมสำหรับผู้ดูแลระบบ

---

## 🌟 จุดเด่นและฟังก์ชันหลักของระบบ (Core Features)

### 1. โครงสร้างสิทธิ์การใช้งาน (Roles & Permissions)
- **โหมดคุณครูและบุคลากร (User Mode)**:
  - สิทธิ์ดูตัวอย่าง (Preview) และดาวน์โหลดเอกสาร (Download) ไปปรับใช้ในรูปแบบอ่านอย่างเดียว (Read-Only)
  - ค้นหาเอกสาร กรองตามฝ่ายงาน กรองตามหมวดหมู่ย่อย และแท็ก
  - บันทึกเอกสารที่ใช้บ่อยไว้ในรายการโปรด (Bookmarks/Favorites)
- **โหมดผู้ดูแลระบบ (Admin Mode)**:
  - สิทธิ์เต็มรูปแบบ (Full Access)
  - อัปโหลดเอกสารใหม่ผ่านระบบ **Drag & Drop** (ลากไฟล์มาวาง)
  - กำหนดฝ่ายบริหาร ๔ ฝ่าย หมวดหมู่ย่อย แท็กป้ายกำกับ และคำอธิบาย
  - แก้ไขข้อมูลเอกสาร (Edit Metadata) และลบเอกสาร (Delete)
  - สรุปสถิติยอดดาวน์โหลดและยอดเข้าชมของแต่ละเอกสาร

### 2. โครงสร้างการจัดเก็บข้อมูล ๔ ฝ่ายบริหาร (Information Architecture)
1. **หมวดงานวิชาการ**:
   - หลักสูตรสถานศึกษา / โครงสร้างเวลาเรียน ๒๕๖๙
   - สื่อการสอน / แผนการจัดการเรียนรู้ Active Learning (รูปแบบ ๔ คิด, STEM)
   - แบบฟอร์มนิเทศการสอนออนไลน์และในชั้นเรียน
2. **หมวดงานบุคลากรและบริหารทั่วไป**:
   - คำสั่งโรงเรียน / ประกาศ / ระเบียบการ
   - แบบฟอร์มขออนุญาต (ลากิจ, ลาป่วย, ไปราชการ)
   - แบบฟอร์มเสนอขอรับรางวัล (คุรุชนคนคุณธรรม, นวัตกรรมสร้างสรรค์คนดี)
3. **หมวดงานกิจการนักเรียน**:
   - คู่มือการดำเนินงานสภานักเรียน / คู่มือมาตรการความปลอดภัย
   - เอกสารและแบบรายงานโครงการโรงเรียนคุณธรรม สพฐ.
4. **หมวดงานงบประมาณและพัสดุ**:
   - แบบฟอร์มขออนุมัติจัดซื้อจัดจ้างพัสดุ/สื่อการเรียนรู้
   - รายงานสรุปผลการใช้จ่ายงบประมาณรายไตรมาส

### 3. ระบบค้นหาและพรีวิวอัจฉริยะ (Smart Search & Instant Preview)
- **Live Search**: ค้นหาแบบเรียลไทม์ตามชื่อไฟล์ คีย์เวิร์ด หรือแท็กป้ายกำกับ
- **Cross-Category Tags**: คลิกแท็ก (เช่น `#รูปแบบ 4 คิด`, `#ป.4`, `#แบบฟอร์มลา`) เพื่อสืบค้นข้ามหมวดหมู่ได้ทันที
- **Simulated Thai Official Document Preview**: หน้าต่างดูตัวอย่างเอกสารจำลองรูปแบบราชการไทย (ตราครุฑ/ตราโรงเรียน, รูปแบบบันทึกข้อความ, เกณฑ์ประเมิน, ลายเซ็น) สามารถซูม ย่อ-ขยาย พิมพ์ (Print) และคัดลอกลิงก์ได้โดยไม่ต้องดาวน์โหลดลงเครื่องก่อน

## 🚀 วิธีการนำขึ้น Vercel (Deploy to Vercel.app)

โปรเจกต์นี้เป็น Zero-Config Static Web Application ซึ่งพร้อม Deploy บน Vercel ได้ทันที มี 2 วิธีที่สะดวกที่สุดดังนี้:

### วิธีที่ 1: Deploy ผ่าน GitHub (แนะนำที่สุด - อัปเดตอัตโนมัติ)
1. นำโฟลเดอร์โปรเจกต์นี้ขึ้น GitHub Repository ของท่าน:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Kru Sauce Document Hub"
   git branch -M main
   git remote add origin https://github.com/<your-username>/watbangpun-doc-hub.git
   git push -u origin main
   ```
2. ไปที่เว็บไซต์ [Vercel.com](https://vercel.com) และเข้าสู่ระบบ
3. คลิกปุ่ม **"Add New..."** -> เลือก **"Project"**
4. เลือก GitHub Repository ที่เพิ่งสร้าง แล้วกด **"Import"**
5. ในหน้าตั้งค่า Vercel ไม่ต้องแก้ไขค่าใดๆ (Framework Preset: Other) แล้วกดปุ่ม **"Deploy"**
6. ระบบจะสร้าง URL เช่น `https://watbangpun-kru-sauce-hub.vercel.app` ให้ทันที ใช้งานได้ทั่วโลกและรองรับอุปกรณ์มือถือ/แท็บเล็ต/คอมพิวเตอร์

---

### วิธีที่ 2: Deploy ผ่าน Vercel CLI (รวดเร็วผ่าน Terminal)
1. หากมี Node.js และ Vercel CLI ในเครื่อง:
   ```bash
   npm i -g vercel
   ```
2. รันคำสั่ง deploy ในโฟลเดอร์นี้:
   ```bash
   vercel
   ```
3. ทำตามคำแนะนำบนหน้าจอเพื่อเชื่อมต่อกับบัญชี Vercel และรับลิงก์ `.vercel.app` ได้ทันที

## 💻 การทดสอบและเปิดใช้งานในเครื่อง (Local Testing)
- สามารถเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Safari, Firefox) โดยการดับเบิ้ลคลิกไฟล์โดยตรง
- ข้อมูลทั้งหมด (การอัปโหลด, แก้ไข, ลบ, บันทึกโปรด) มีระบบ LocalStorage ช่วยจดจำข้อมูลในเครื่องอย่างต่อเนื่อง
